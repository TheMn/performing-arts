# Optional assets

Both files are optional — the demo runs without them.

- `farandole.mid` — the Farandole MIDI file (e.g. from IMSLP or MuseScore). Without it the demo plays short
  placeholder loops in D and shows a banner. You can also just drag a `.mid` file onto the page.
- `dance.jpg` — a photo of Matisse's *Dance* (1910) used as the background (cover-fit). Without it the
  demo paints a flat blue / green field.

Until you add them the browser console shows two harmless `404` lines for these files.
